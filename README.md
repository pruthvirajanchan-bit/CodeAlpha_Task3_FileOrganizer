# CodeAlpha Task 3: JPG File Organizer

## Project Overview

A Python automation project that organizes JPG and JPEG files into a separate folder.

## Features

* Automatically moves JPG and JPEG files.
* Accepts the source folder path from the user.
* Creates a destination folder named `JPG_Images`.
* Displays the total number of files moved.
* Handles missing folders and file-moving errors.

## Technologies Used

* Python 3
* os module
* shutil module

## How to Run

1. Install Python 3.
2. Download `file_organizer.py`.
3. Open a terminal in the folder containing the file.
4. Run `python file_organizer.py`.
5. Enter the folder path containing JPG or JPEG images.
